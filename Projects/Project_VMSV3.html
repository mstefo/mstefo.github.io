What Is Vivid Management System (V3)?

The Vivid Management System (VMS) is a proprietary application for Vivid Property Services (Vivid). It is designed to assist Vivid employees with their administrative tasks on all levels, whether they track their KPIs and metrics on the operation level or carry out customer support by organising Work Orders.

Key Contributions

The system is being rebuilt from the ground up due to the impossibility of maintaining the old version. This new version, dubbed Version 3 (V3), was designed with an MVC pattern as a Content Management System (CMS). My role at Vivid is to help transfer the old modules of VMS into V3.

  • Redesigned and created a user-friendly Form Builder to allow Vivid Employees to create dynamic Audit forms to assess our cleaning duties
  • Integrated the FusionCharts JavaScript library to create powerful business intelligence charts & created a dynamic GUI to easily create advanced charts using this framework
  • Implemented real-time AutoSaving for user audits on the field with jQuery, ColdFusion and JavaScript
  • Incorporated multiple RESTful APIs for supply chain ordering of consumable items (e.g. soap, tissues etc.)
  • Designed and maintained a Microsoft SQL database for storing of all business data
