Portfolio Website

What Is Portfolio Website?

It is the website you are viewing this page on. This project was developed with the sole intention of showcasing all the projects I have developed. It is a lightweight site built using HTML, CSS and simplistic Javascript. This was done as the goals of the project are basic, thus necessitating a straightforward implementation.

The website received a refactor in August 2026, implementing jQuery and an MVC design pattern to better improve maintainability as new projects are developed. jQuery was added to enable more dynamic effects.

Key Contributions

  • Designed Website aesthetics and colour scheme
  • Implemented design through CSS
  • Developed backend Javascript/jQuery code
  • Created HTML page layout
  • Incorporated an MVC pattern to match industry standards
